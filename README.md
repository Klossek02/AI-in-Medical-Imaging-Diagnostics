# AI-in-Medical-Imaging-Diagnostics
Repository to track the progress for AI in Medical Imaging Diagnostics project

## EDA
EDA was done in `EDA/datasets_eda.ipynb` using Python 3.9.21 and packages from `EDA/requirements.txt`.

Datasets' sources:
- [SPIDER](https://zenodo.org/records/10159290)
- [Lumbar spine MRI](https://data.mendeley.com/datasets/k57fr854j2/2)
- [Multi-scanner and multi-modal lumbar vertebral body and intervertebral disc segmentation database](https://www.nature.com/articles/s41597-022-01222-8)
